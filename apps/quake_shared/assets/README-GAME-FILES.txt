Quake 1 for GeminiTop requires user-supplied game data.

Place your retail Quake files here:

  id1/pak0.pak
  id1/pak1.pak

The launcher wrappers keep writable data on the USB payload under:

  .tyrquake/id1
  .tyrquake/qw

QuakeWorld quick start:

1. Connect WiFi in Gemini Launcher first.
2. Launch QuakeWorld.
3. Open the console with the backquote/tilde key.
4. Type:

   connect server:port

Example:

   connect quake.example.org:27500
