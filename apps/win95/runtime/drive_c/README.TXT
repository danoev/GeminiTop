Windows 95 launcher is ready, but no licensed HDD image is installed yet.

Expected image path:
  apps/win95/images/system.img

Use your own preinstalled or self-installed Windows 95 HDD image. DOSBox-X
will boot it directly from this launcher entry.

Controls:
  Ctrl+F9   Exit back to Gemini Launcher
  Ctrl+F10  Toggle mouse capture

Note:
  The default config is tuned for a software-rendered first pass and uses
  APM BIOS so a guest shutdown can power off DOSBox-X cleanly.
